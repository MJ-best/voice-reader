# Google Play 스토어 등록정보 (ko-KR)

## 앱 이름 (30자)
보이스 리더 - EPUB 낭독

## 간단한 설명 (80자)
내가 고른 목소리로 EPUB을 읽어 주는 오프라인 리더. 자연스러운 한국어 낭독.

## 자세한 설명 (4000자)
보이스 리더는 내가 고른 목소리로 EPUB 책을 읽어 주는 이북 리더입니다. 목소리는 기기 안에서 만들어지므로 음성 팩을 한 번 받고 나면 인터넷 없이도 들을 수 있습니다.

■ 한국어를 제대로 읽는 낭독
· 숫자를 단위에 맞게 읽습니다: 3개 → 세 개, 21명 → 스물한 명, 6월 → 유월
· 날짜, 시간, 단위(km·kg·%), 전화번호, 영문 약어(AI → 에이아이), 한자 병기, 성경 구절(요 3:16 → 요한복음 삼장 십육절)
· 잘못 읽는 단어는 길게 눌러 '발음 고치기'. 이 책만 또는 모든 책에 적용하고, 고치면 바로 다시 읽어 줍니다
· 괄호 안 내용, 각주 기호, 영문 약어 풀어 읽기를 켜고 끌 수 있습니다

■ 소설을 두 목소리로
· 따옴표로 시작하는 대사만 다른 목소리로 읽습니다(예: 서술은 여성, 대사는 남성)
· Supertonic 음성 팩의 목소리 10종(여성 5, 남성 5) 또는 기기 기본 TTS
· 직접 만든 목소리 파일을 넣어 내 목소리로 들을 수도 있습니다

■ 편하게 듣기
· 읽는 문장 하이라이트, 페이지 자동 넘김
· 화면을 끄고 듣기, 잠금화면·이어폰 버튼, 장 이동
· 다음 문장을 미리 만들어 끊김 없이 이어 읽습니다
· 속도와 문장 사이 쉼 조절, 서재의 '이어 듣기' 카드

■ 서재와 읽기
· 책장으로 정리: 자동 책장(읽는 중)과 직접 만든 책장
· 테마(라이트·세피아·다크), 글꼴(명조·고딕), 글자 크기, 줄 간격
· 줄긋기, 목차, 이어 읽기
· 영어 원서의 어려운 단어 아래에 쉬운 영영 힌트(Word Wise), 낭독할 때는 힌트를 건너뜁니다

■ 흑백 e-ink 기기에 맞춘 화면
· 애니메이션과 그림자 없이 테두리로 그린 순수 흑백 화면
· 큰 글씨와 넓은 터치 영역, 기기의 페이지 버튼과 볼륨 키로 쪽 넘기기

■ 개인정보
· 회원 가입, 광고, 분석 도구가 없습니다
· 책과 읽기 기록은 기기 밖으로 나가지 않습니다
· 인터넷은 음성 팩(약 96~145MB)을 받을 때만 씁니다

DRM이 없는 EPUB 파일을 읽습니다. DRM이 걸린 책은 열지 않고 알려 드립니다.
