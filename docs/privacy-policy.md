# 개인정보처리방침 (보이스 리더)

최종 수정: 2026년 11월 19일

보이스 리더(Voice Reader, 패키지 `app.voicereader`)는 개인이 만든 비상업 오픈소스 이북 리더입니다. 이 문서는 앱이 다루는 정보를 설명합니다.

## 수집하는 정보

**없습니다.** 앱에는 회원 가입, 광고, 분석 도구, 오류 보고 도구가 없으며 개발자는 사용자에 관한 어떤 정보도 받거나 저장하지 않습니다.

## 기기 안에만 저장되는 정보

다음 정보는 사용자의 기기 안에만 저장되고 기기 밖으로 보내지지 않습니다.

- 사용자가 고른 EPUB 파일과 서재·책장, 읽은 위치, 줄 그은 곳
- 발음 사전, 읽기 설정, 고른 목소리
- 사용자가 직접 가져온 음성 팩, 목소리 파일, 녹음 파일

앱을 지우면 이 정보도 함께 지워집니다.

## 인터넷 사용

앱은 사용자가 **음성 팩 받기**를 눌렀을 때만 인터넷을 씁니다. 이때 Hugging Face(huggingface.co)에서 공개된 음성 모델 파일을 내려받습니다. 책 내용이나 개인 정보는 보내지 않습니다. 파일을 내려받는 동안 Hugging Face는 일반적인 웹 요청처럼 IP 주소 등 접속 정보를 받을 수 있으며, 이는 [Hugging Face 개인정보처리방침](https://huggingface.co/privacy)을 따릅니다.

## 권한

- 미디어 재생(포그라운드 서비스), 화면 꺼짐 방지: 화면을 끈 채 낭독을 이어 가기 위해 씁니다.
- 인터넷: 음성 팩을 받을 때만 씁니다.
- 저장소 읽기(Android 12 이하): 기기 안의 EPUB을 찾을 때만 씁니다.

## 아동

이 앱은 아동을 대상으로 하지 않으며, 아동을 포함한 누구의 정보도 수집하지 않습니다.
